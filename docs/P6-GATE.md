# P6 Gate — Metadata, OG Images, SEO, JSON-LD

**Adjudicator:** Finish-Gate Reviewer (UI)

## Decision: **PASS**

Metadata, OG image, sitemap, robots, and JSON-LD all ship. The site is
shareable and crawlable.

## Evidence

1. **`generateMetadata` on every page route.** Home, `/work`,
   `/work/[slug]`, `/craft`, `/notes`, `/about`, `/colophon`,
   `/contact`. Title template `"%s · Gustavo Bispo"` set in the root
   layout.

2. **Open Graph image generated by code.** `app/opengraph-image.tsx`
   uses `ImageResponse` from `next/og`. Built-in Geist font from
   `next/dist/compiled/@vercel/og/Geist-Regular.ttf` — no extra
   dependency. Renders at 1200×630, PNG, ~55 KB. The image carries the
   engineer's mark, role, positioning, status, and site URL.

3. **Per-case-study OG metadata.** `generateMetadata` in the case study
   template sets the OG title to the project title + company.

4. **Sitemap is generated.** `app/sitemap.ts` returns seven static
   routes plus three case study URLs, with `lastModified`, `changeFrequency`,
   and `priority`. `_design` and `/api/` are not listed (the latter
   does not exist; the former is `noindex`).

5. **Robots is generated.** `app/robots.ts` allows `/`, disallows
   `/_design` and `/api/`, and points to the sitemap. The `/_design`
   route is also `noindex,nofollow` via its own metadata.

6. **JSON-LD Person on the home.** `application/ld+json` script with
   `@type: Person`, name, jobTitle, url, sameAs (filtered to skip
   placeholders), and knowsAbout list.

7. **JSON-LD BreadcrumbList on case study pages.** Two crumbs:
   `work` and the slug. URL derives from the canonical site base.

8. **JSON-LD CreativeWork on case study pages.** name, author, about
   (the company), datePublished (the period), keywords (the stack),
   url, description.

9. **No raw colors in JSON-LD or OG image.** The OG image uses literal
   hex `#1a1a1a` and `#f5f5f5` because `ImageResponse` requires inline
   styles and does not read CSS custom properties. This is the brief's
   documented exception: tokens cannot cross the OG generator boundary.
   The exception is documented here, not hidden.

10. **Build clean.** 17 routes generate. Zero warnings.

## Findings (forward-looking)

1. **JSON-LD includes placeholder strings for the name and social
   handles.** When the real values arrive, they will replace the
   `sameAs` empty array with real URLs. The Person schema stays valid
   through the placeholder window because every required field has a
   string (even if it begins with `[[PLACEHOLDER`).

2. **OG image uses the placeholder name.** When the real name is
   supplied, the OG image updates on next build.

3. **The `_design` route is `noindex,nofollow`.** It is an internal
   review surface, not a public page.

Advance to P7 (ArchitectUX — Performance + accessibility pass with
measured numbers).

— Finish-Gate Reviewer, P6
